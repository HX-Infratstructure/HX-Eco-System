Purpose

Deep Agents on HX-12 is the HX line-of-business agent factory/application-agent harness. BASE PASS must prove that it can create and run a small domain agent package; package import or a plain LLM response is not sufficient.

Role boundary

HX-5 DeepSeek Harness
META-AGENT / broad AI-solution orchestration
        ↓
HX-12 Deep Agents
LOB AGENT FACTORY / application-agent harness
        ↓
Domain agents used by line-of-business applications

Current upstream basis

Planning review on September 9, 2026 found deepagents==0.7.13 as the current stable Python release. Deep Agents is a batteries-included harness built on LangChain/LangGraph with sub-agent delegation, filesystem tools, context management, optional shell access, skills, memory, and custom/MCP-compatible tools. The accepted version must be re-verified and pinned at implementation time.

Critical preflight

The selected HX model must prove reliable tool calling before the full test: at minimum one filesystem operation and one task sub-agent delegation. Ordinary chat completion does not establish compatibility.

LOB Agent Factory smoke test

Deep Agents creates a disposable package named approximately hx-lob-agent-smoke for a synthetic service-case routing scenario.

bounded synthetic LOB requirement
          ↓
Deep Agents builder on HX-12
          ↓
real generated LOB agent package
          ↓
Deep Agent supervisor
          ↓
Intake Agent / Business Rule Agent / Reviewer Agent
          ↓
known-answer routing result + validation

The example critical outage case must resolve to Operations / P1 under the supplied synthetic business rules.

Expected artifacts

Deep Agents-specific proof

  • real filesystem artifact creation;
  • at least two distinct domain sub-agents, three preferred;
  • actual task delegation using stable isolated sub-agents;
  • context handoff between delegated work;
  • business-rule/tool use;
  • structured known-answer output;
  • independent validation;
  • same-thread context continuity using a disposable checkpointer;
  • reboot persistence of the pinned environment and smoke package.

Closure rule

Deep Agents environment/runtime health = PASS
                    AND
approved-model tool-calling compatibility = PASS
                    AND
LOB agent creation + execution smoke test = PASS

Not required for BASE PASS

Production LOB data, production UI/API deployment, permanent MCP or OmniRoute wiring, PostgreSQL/Redis persistence, Qdrant/LightRAG, Mem0, NFS, external cloud models, experimental fork sub-agent mode, and containers are explicitly outside this smoke-test boundary.
