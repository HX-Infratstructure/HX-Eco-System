Key controls

  • No test harness or general-purpose runner dependencies are left on the SUT.
  • No container runtime is installed.
  • Python dependencies are pinned; Ubuntu clients follow supported distro updates.
  • Smoke-test criteria cannot be edited inside an in-progress run.
  • PASS requires functional proof plus cleanup verification.
  • Evidence promotion never auto-commits.
  • UI evidence requires expected live-state text, not merely a rendered page.

Bootstrap

cd "$HX_ECO_REPO"
bash docs/03-runbooks/HX-5/04-centcom-smoke-runner-bootstrap.sh
export PATH="$HOME/.local/bin:$PATH"
hx-smoke-doctor
hx-smoke-doctor --remote

The remote activation probe uses already-PASS HX-2 by default and expects HX-CENTCOM-RUNNER-PASS. DeepSeek Harness is not required for CentCom runner activation.
