HX Eco-System — Skill Governance

Skills augment HX expertise; they do not define HX architecture.

Owner decision
  > current HX control / architecture
  > live HX evidence
  > current runbook / standard
  > governed HX skill + current official vendor guidance
  > history / general knowledge

Canonical source

skills/ is the only canonical HX skill library. Agent-specific installations are derived deployments.

Classes

HX_NATIVE · VENDOR_OFFICIAL · COMMUNITY · WRAPPER · META

Lifecycle

DISCOVERY · PILOT · APPROVED · BLOCKED · RETIRED

Key controls

  • HX context loads before vendor advice.
  • Vendor skills cannot change host placement, native/systemd deployment, network/security/storage architecture, model placement, or smoke PASS criteria.
  • Skills never store credentials or sshpass passwords.
  • Infrastructure-changing execution remains in approved HX runbooks/execution artifacts.
  • HX wrapper skills must validate and package successfully before APPROVED.
