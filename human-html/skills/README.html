Controls

Skills cannot override HX architecture, server placement, native/systemd deployment, network/security/storage rules, model placement, or smoke-test acceptance criteria. Skills do not store credentials.

For Redis, the wrapper does not direct-install the upstream eight-skill bundle. Cluster/replication and Redis Cloud-only AI services are reference-only for current BASE; TLS/firewall/bind/global-command hardening remains owner-controlled; runtime/package/persistence/memory/MCP choices remain subject to current HX authority.
