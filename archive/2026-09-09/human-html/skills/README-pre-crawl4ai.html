Controls

Skills cannot override HX architecture, server placement, native/systemd deployment, network/security/storage rules, model placement, or smoke-test acceptance criteria. Skills do not store credentials.

For Redis, the wrapper does not direct-install the upstream eight-skill bundle. Cluster/replication and Redis Cloud-only AI services are reference-only for current BASE; TLS/firewall/bind/global-command hardening remains owner-controlled; runtime/package/persistence/memory/MCP choices remain subject to current HX authority.

For Mem0, the wrapper uses official OSS/self-hosted guidance for HX-13 while keeping hosted Platform, Vercel, repository-writing pipelines and coding-assistant plugins gated or reference-only. The exact assigned HX-13 MCP implementation is not selected by the skill.

For Docling, the wrapper preserves HX-16 native/systemd placement and owner decision D-006: Granite-Docling 258M stays on HX-16 and is CPU-first for BASE. Containerized Docling Serve and managed replacement are rejected; remote service/VLM, RAG integrations, package/extras, GPU optimization, and MCP mode/transport remain gated by HX authority.
