HX Eco-System Skills Architecture

Ecosystem first. Skill second. Execution third. Validation fourth.

HX owner decisions + current ecosystem authority
  ↓
HX component context
  ↓
HX skill wrapper
  ↘ current vendor skill/docs
  ↓
HX runbook / standard
  ↓
HX smoke roadmap + exact test
  ↓
evidence

Canonical source

skills/ is the governed source for reusable agent expertise. Claude Code, Codex, OpenCode, and other agent-specific locations are deployment targets only.

Initial implementation

Qdrant on HX-10 uses skills/qdrant/hx-qdrant-advisor/, combining stable HX context with live official Qdrant Advisor guidance.

Controls

Skills cannot override HX architecture, server placement, native/systemd deployment, network/security/storage rules, model placement, or smoke-test acceptance criteria. Skills do not store credentials.
