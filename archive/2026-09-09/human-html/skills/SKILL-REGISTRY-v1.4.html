Mem0 provenance

Reviewed official mem0ai/mem0 main 02f7a9b2c4fe38dedb96631e48c85c74ad58b605. Source versions at review: Python mem0ai 2.0.20 and TypeScript mem0ai 3.1.6. The official catalog contains six skills: three reference skills and three on-demand pipeline skills. The portable coding-agent plugin is version 0.3.1 and includes a stdio MCP server; the separate mem0ai/mem0-mcp repository is archived.

Mem0 HX boundary

The mem0 reference skill is adapted for native/self-hosted HX-13 OSS. CLI, Vercel, repository integration/testing pipelines, hosted Platform, and coding-assistant plugin/MCP guidance remain gated or reference-only unless separately admitted. mem0-oss-to-platform conflicts with the current HX-13 runtime unless the owner changes the architecture. Skill approval does not advance HX-13 build state or select its package/service/data/network/model/MCP design.

Redis provenance

Redis HX boundary

Cluster/replication, Redis Cloud LangCache and managed Agent Memory are reference-only for current BASE. Skill approval does not advance HX-9 build state or select runtime/package/persistence/memory/MCP choices.

PostgreSQL provenance

Open HX decisions

Redis and PostgreSQL remain subject to their current owner/runbook decisions for runtime/package, data/persistence, listener/authentication/network, memory/topology and exact MCP implementations. Mem0 remains subject to future HX-13 owner/runbook decisions for package/environment, service/API shape, config/data paths, permanent Qdrant/model bindings, memory lifecycle, network/access pattern and assigned MCP implementation. HX-9 and HX-13 remain NOT STARTED.
