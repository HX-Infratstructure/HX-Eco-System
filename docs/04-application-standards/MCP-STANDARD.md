# Application MCP Standard

Product-specific MCP servers are installed with their parent applications during base build.

The MCP server must receive an independent smoke test before the parent server can close BASE PASS.

MCP registration with agents, DeepSeek Harness, Open WebUI, or workflow clients is integration-phase work.

HX-15 FastMCP is reserved for shared/custom MCP development and runtime patterns; it is not a gate for native/product-specific MCP servers.
