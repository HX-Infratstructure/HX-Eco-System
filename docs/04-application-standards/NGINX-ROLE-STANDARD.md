# NGINX Role Standard

HX-7 NGINX is a development/test rendering utility.

Use it when an application under active development needs its UI rendered/proxied through NGINX for development or testing.

Do not use HX-7 as the general front door for Qdrant Web UI, LightRAG, n8n, Open WebUI, PostgreSQL/Redis consoles, MCP servers, or other normal HX ecosystem services.
